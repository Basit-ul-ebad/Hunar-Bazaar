# Hunar Bazaar design files

- `screens/`: PNG of every screen at 2x (780 × 1688 px; the style guide is 1720 px wide). The file name prefix matches the screen ID in DESIGN.md (B1–B3, S1–S3, L1–L6, O1, U1).
- `html/`: the exact HTML/CSS of each screen. Open one in a browser to inspect exact sizes, paddings and colours.
  Mapping: Main=B1, BuyerShop=B2, MyShop=B3, SignIn=S1, Setup=S2, Home=S3, AddPhoto=L1, AiThinking=L2,
  CheckDetails=L3, FairPrice=L4, CatalogCard=L5, Shared=L6, Profile=O1, HomeUrdu=U1, StyleGuide=style guide.

Product images in the screens are placeholder patterns (phulkari, ajrak, ralli, blue pottery). Real photos replace them.
